# Prologs

Starter mobile storefront for Android and iPhone using Expo/React Native.

## Current stage
- White + blue Prologs branding
- Home screen
- Search
- Product listing
- Product details
- Cart placeholder
- Account screen
- Login screen

## Next production stage
Connect a secure backend/database, real authentication, payments, order management, and the phone-friendly admin dashboard.

Do not place real customer credentials or sensitive data in this starter project.
